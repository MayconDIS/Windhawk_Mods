# New mod checklist

- [ ] Name, unique ID, purpose, and supported processes
- [ ] Self-contained `mods/<id>.wh.cpp` source
- [ ] Entry in `mods.json` and root README
- [ ] English quick start and settings reference
- [ ] Original project artwork or appropriately licensed assets
- [ ] Scope, limitations, and disable/recovery behavior
- [ ] Build and behavior validation
- [ ] Version/change notes
- [ ] Credits for every upstream component
- [ ] Final links to the repository and maintainer profile
